## Важное

1. **leknorm / lessons.js, урок 2, «Главное»** — новая фраза «Верные сочетания: одержать победу, оказать помощь, причинить вред, произвести впечатление.»
   Оценка: это правка теории ради счёта слов-основ (шесть лемм — одержать, победа, оказать, причинить, произвести, впечатление — как раз стоят ровно на потолке 10 в `povtory.py`; фраза делает их «словами из формулировки правила»). Для ученика сама по себе она бесполезна: четыре словосочетания даны голым списком, без связи с ошибкой, которую правило исправляет. Эти же пары уже есть в теле урока (таблица, строки 131–135, и список, строки 167–168). Как честное объяснение фразу можно оставить, только если связать её с ошибкой; иначе — убрать и вернуть слова-основы к обычной норме.
   Замена (честное объяснение вместо голого списка):
   `Смешение двух оборотов (контаминация) исправляют, восстановив любой из них: играть роль — иметь значение. Так же: одержать победу (не «одержать поражение»), оказать помощь (не «оказать вред»), причинить вред (не «причинить помощь»), произвести впечатление (не «оказать впечатление»).`
   Вариант без замены: удалить фразу целиком и перенести в заметки главы (`docs/plans/leknorm.md`) список слов-основ без неё (в заметках пока 12–14 лемм с обоснованием «слова из „Главного“» — после правки обоснование надо привести в соответствие).
