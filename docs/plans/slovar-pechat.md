## 2. «Ультимативный школьный словарь» ✅ решено · ⏳ не начато
**Что хочет владелец:** расширить «Умный словарь» (сейчас 50 статей) и словарик правописания (254 слова) до **нескольких тысяч** самых нужных слов, включая слова из художественной литературы, которых нет в наших упражнениях (подпоручик, кафтан, куцый, коммюнике…): дети их не знают — это нормально, словарь должен помочь. Сотни тысяч слов не нужны.
- **Источники (важно):** «взять чужие словари и объединить» — только **открытые**: Русский Викисловарь (CC BY-SA, выгрузка уже используется), OpenCorpora/pymorphy3 (формы; CC BY-SA). Ожегов, Тихонов, Ефремова, Лопатин и другие закрытые словари **копировать нельзя** (`CLAUDE.md`, «Нельзя»; `docs/DICTIONARY.md`) — только сверка. Значения упрощаются и переписываются своими словами. Свежая выгрузка Викисловаря с синонимами и морфемами — `dumps.wikimedia.org` (с 28.11.2026 из среды доступен; `ru.wiktionary.org` — по 301, проверить).
- **Список слов:** (а) частотность в корпусе русской классики (`tools/lit`, ~270 тыс. предложений, 24 автора) — слова, которые школьник встретит в программе, но не знает; (б) словарик правописания и `pilot-words`; (в) слова из упражнений, тренажёра и тестов глав; (г) отдельный слой «историзмы, архаизмы, диалектизмы, иностранные слова» (подпоручик, кафтан, коммюнике). Школьной программы по литературе 5–11 классов.
- **Статья нового словаря** — двух уровней: **лёгкая** для всех (значение простыми словами, ударение, часть речи, пример из классики, помета «устар./разг./книжн.», формы автоматически) и **полная** (морфемный разбор, словообразование, гнездо, синонимы…) — только для ядра и слов из программы. Полную для тысяч слов писать не надо.
- **Вес:** не раздувать `index.html` (27 МБ) — данные словаря отдельным файлом, постепенная загрузка (решение 20.11, связано с `dva-rezhima.md`, шаг 1). Поиск слова — единый, из `#dict` и общего поиска.
- **Проверка:** партии по 25–50 слов, независимый рецензент (как в пилоте), правки скриптом.
- Открытое для владельца 🔶: нужен ли объём 3 000, 5 000 или «сколько выйдет по корпусу» (предложение Claude: ≈ 5 000 слов: 3 000 лёгких + 1 500 с историзмами/иностранными + ядро с полными статьями).

## 3. Печатная (текстовая) версия — переработка ✅ решено · ⏳ не начато
**Что хочет владелец:** отдельная **не интерактивная** книга, которую можно скачать, отправить, поделиться. Состав и порядок: **сначала вся теория, потом упражнения, и только в самом конце книги — тесты по каждой теме, собранные вместе.** Задания тренажёра можно частично пустить в тесты.
- Основа уже есть: `tools/print.py` + `src/js/core/print.js` + `src/css/printbook.css` (глава за главой: теория → схемы статично → тренажёр → упражнения → тесты). Нужно **переставить порядок**: по всей книге (или по главе — решить) части «Теория», «Упражнения», «Тесты» идут блоками; тесты — в конце книги, по главам; ключи — только версия учителя, отдельным разделом.
- Решить 🔶: (а) порядок «вся теория → все упражнения → все тесты» на **весь учебник** (одна толстая книга, ~51 глава) или то же внутри каждого **раздела/ступени** (книга-том на ступень); предложение Claude: том на раздел (9 томов) + сводный файл; (б) что идёт в «тесты»: тесты глав + часть заданий тренажёра (где можно выполнить на бумаге); (в) режимы «Проще»/«Углублённо» — отдельные издания (обычное, углублённое) или всё вместе; (г) формат выдачи: HTML для печати уже есть, нужен **PDF** (скачать и переслать) — собирать в Actions (Chromium есть) и выкладывать файлом; (д) словарь в печати — приложением?
